# 限流配置：需求

状态：已实施并通过本地验证。

## 范围与现状

`bootstrap/route.go` 当前以 5000 次和 1 秒构造进程内 IP 限流器。
沿用 `.env`/环境变量配置体系，新增 `RATE_LIMIT_REQUESTS` 和 `RATE_LIMIT_WINDOW`，
默认值保持 5000 和 1s。main 将配置显式传给 bootstrap，不改变限流算法或作用范围。

## 验收标准

- 未配置时行为不变；显式配置可以改变每个 IP 的允许次数和时间窗口。
- 次数必须是正整数；窗口必须是正 Go duration；非法配置在启动时拒绝，不静默回退。
- 配置示例和使用文档同步；变更后需重启进程。
- 不引入依赖，不改真实 .env，不自动提交或推送。

## 验证

配置解析边界测试及 bootstrap 限流装配测试；执行 gofmt、go vet ./...、
go test ./...、go test -race ./...、go build ./... 和 git diff --check。

验证结果：以上检查通过。测试覆盖默认值、自定义次数/窗口、零值、负值、非整数、
溢出、非法 duration，以及配置次数在 bootstrap 全局中间件中生效和 IP 隔离。
