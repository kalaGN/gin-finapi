# 认证契约合并：设计

创建日期：2026-10-14。用户确认将 app/auth/credential.go 合并到现有 app/services/auth.go。

## 范围与兼容性

- Credential 和 ProductAccess 仍是存储无关的凭据/授权快照；字段、JSON tag、解析规则不变。
- ErrInvalid 更名为 services.ErrAPIKeyInvalid，ErrUnavailable 更名为 services.ErrAuthUnavailable；
  ErrProductDenied 保持名称。三个错误文案不变，认证错误不得与查询 services.ErrUnavailable 合并。
- 同步中间件、缓存读取层、Redis 适配器、bootstrap 及所有测试的引用。
- services 不导入 Gin、Redis、Mongo、configdata 或 middleware，避免循环依赖和业务层反向依赖。
- pkg/redis 已有 APIKeyCredential、ErrAPIKeyInvalid、ErrAuthUnavailable 别名指向新类型/错误，保留既有调用形式。
- 全部引用迁移后移除旧 credential.go，不保留转发包；不改变 HTTP 状态、业务码、签名、缓存或数据访问。
