# Gin FinAPI 项目更名：需求

> 状态：已确认并实施；2026-10-11 用户确认采用“最小影响改动”。

## 目标

将当前项目身份从 `Airis`/`airis` 更新为 `Gin FinAPI`/`gin-finapi`，并使 Go module 与已更名的
GitHub 仓库 `github.com/kalaGN/gin-finapi` 一致，不改变 HTTP、数据或部署行为。

## 技术与结构

- Go 版本、Gin/Mongo 等依赖版本保持不变。
- `go.mod` 和仓库内 Go imports 迁移到 `github.com/kalaGN/gin-finapi`。
- 活跃入口文档、规则索引、README、构建产物名和压测脚本展示名使用新名称。
- 代码布局、包名、路由和配置键保持不变。

## 命令与测试

在仓库根目录执行：

```bash
gofmt -l $(git ls-files '*.go')
go mod verify
go vet ./...
go test ./...
go test -race ./...
go build ./...
go build -o /tmp/gin-finapi main.go
git diff --check
```

## 最小影响边界

### 本次修改

- Go module 和内部 import path。
- 当前项目标题、简介、目录示例、构建二进制及 Docker 镜像示例名称。
- 活跃 Rules、Specs/Knowledge 索引和当前项目审计中的项目名称。
- 压测工具面向用户展示的项目名称。

### 本次保留

- MySQL 数据库/用户 `airis`、Redis Key 前缀 `airis:`、`/etc/airis/` 等已有或拟定数据/运维标识；
  改动它们可能需要数据迁移和兼容方案。
- 本地工作目录 `/Users/wangfei/GolandProjects/airis`；目录名不影响仓库或 Go module 身份。
- 历史性能报告、迁移设计和已完成 Spec 中的历史名称。
- 未进入主链路的 HelloWorld Proto `go_package` 及 `*.pb.go`。仓库未记录生成命令，且本机
  `protoc` 版本与现有生成文件不同，禁止手改生成文件；后续如启用 gRPC 再单独迁移。

## 编码与文档规则

- 只做名称和 module path 的机械迁移，不顺带重构或升级依赖。
- Go 文件保持 `gofmt`；历史文档不改写事实语境。
- 新名称显示为 `Gin FinAPI`，仓库/module/二进制显示为 `gin-finapi`。

## 可测试验收标准

- `go.mod` module 为 `github.com/kalaGN/gin-finapi`，所有已编译 Go 源码不再导入旧 module。
- 活跃入口文档和构建命令使用 `Gin FinAPI`/`gin-finapi`。
- HTTP 路径、JSON、业务码、Mongo 字段和环境变量不变。
- 全量格式、模块校验、vet、测试、race 和构建通过。
- 旧名称只允许保留在明确排除的数据标识、历史文档和未启用 Proto 生成链路中。

## 边界

- 总是：保持最小 diff，验证旧 module import 已清零。
- 先确认：数据/缓存标识、本地目录或 Proto 生成链路迁移。
- 禁止：手工编辑 `*.pb.go`、运行数据初始化脚本、自动 Commit。
