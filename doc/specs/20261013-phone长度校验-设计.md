# phone 长度校验：设计

创建日期：2026-10-13。用户明确要求 phone 必须为 32 或 64 位长度。

## 契约与范围

- JSON phone 保持必填字符串；缺失/空串保持 400/1001，非字符串保持 400/1002。
- 非空字符串按 Go len（字节数，与现有摘要识别一致）限制为 32 或 64；其他长度返回
  400/1002，复用现有手机号错误文案，不截断、补齐或 TrimSpace。
- 只新增长度检查，不额外增加十六进制字符规则。32 位十六进制 MD5 仍截前 20 位查询，
  64 位十六进制 SHA-256 仍返回 503/9002 等待转换服务；32/64 位非十六进制字符串仍原值查询。
- 校验位于 LoanAuth 的 phone 类型/必填校验后，读取凭据、验签和产品授权前。
- phone 不参与签名。禁止新增依赖、数据库变更、报警实现、初始化、服务重启或自动提交。

## 兼容与实施

此需求明确替代之前任意非空标识兼容规则：20 位历史标识与用户旧样例不再被公开接口接受。
不变更 Mongo t 的长度和数据格式，不对测试/生产库实施迁移。
先补长度边界和依赖短路测试，再增加中间件分支；更新相关 HTTP 测试 Fixture、Apifox
和压测样本，以及 README、Rules、Knowledge。保持当前工作树 /api 路由改动和其他用户修改。

## 验收与验证

覆盖 1、20、31、33、63、65 位拒绝，32/64 位接受长度检查；类型、缺失、空串错误不变；
非法长度不得读取凭据、产品授权或进入 Handler。MD5 截断、SHA-256 TODO 和三字段验签回归不变。

仓库根目录执行 go test -race ./...、go vet ./...、go build ./...、go mod verify、
go test -race cmd/init_redis.go cmd/init_redis_test.go、git diff --check。
只 gofmt 修改的 Go 文件；integration 标签先做编译检查，不运行外部数据库测试。
验证完成后补充结果，真实客户端联调与生产数据验证不属于本轮。
